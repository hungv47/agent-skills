## Agent Skills v1.5.2 — repositioned v1 line head

This release repositions `main` as the **v1 line** of agent-skills. The not-yet-merged refactor on `refactor/v2.0` is the **v2 line** (see the [v2.0.0 pre-release](https://github.com/hungv47/agent-skills/releases/tag/v2.0.0)).

`v1.5.2` corresponds to marketplace version `5.2.0` on disk, mapped down to the new v1.minor.patch numbering. It is the head of everything currently shipping on `main` (`a4bef2c`).

### What's on the v1 line at this point

**5 plugins, 24 skills**

- **research-skills** — icp-research, market-research, diagnose, prioritize, funnel-planner, short-form-research, short-form-eval
- **marketing-skills** — brand-system, copywriting, ad-copy, cold-outreach, social-copy, short-form-brief, lp-brief, lp-eval, campaign-plan, design-brief, seo, humanize, vn-tone
- **product-skills** — user-flow, system-architecture, code-cleanup, machine-cleanup, docs-writing
- **meta-skills** — discover, agents-panel, eval-loop, task-breakdown, fresh-eyes, cleanup-artifacts, plus `orchestrate-*` siblings per stack

### What changed since the prior tagged release (`v3.0.0`, May 12)

Eleven commits landed on `main` without a GitHub Release; this `v1.5.2` cut captures them:

- **marketplace 3.1.0** — `lp-brief` absorbs conversion principles; `lp-optimization` deprecated.
- **marketplace 4.0.0** — deprecated `lp-optimization` removed; `marketing-skills` 6.0.0 (BREAKING).
- **marketplace 5.0.0** — BREAKING artifact-tree migration; all 4 stacks bumped major.
- **marketplace 5.0.1** — fresh-eyes patch on 5.0.0.
- **marketplace 5.2.0** — submodule pointer bumps + artifact path migration to `.agents/skill-artifacts/`, CI-ready `--check` flag on `build-registry`, plus `audit-*` / `rewrite-*` / `sanitize-*` helper scripts.

### Why the version renumber

The v1.x → v3.x history accumulated organically (umbrella majors didn't track stack majors), and the latest tagged release (`v3.0.0`) labeled the same product line that the new fresh-start refactor also wants to call "v2". To remove the collision and make the trunk vs. refactor split obvious, `main` is consolidated under the v1 line and the refactor branch owns v2.

### Install

```bash
# Latest v1 line (main, default):
npx skills add hungv47/research-skills
npx skills add hungv47/marketing-skills
npx skills add hungv47/product-skills
npx skills add hungv47/meta-skills

# Or pin to v1.5.2 explicitly:
npx skills add hungv47/agent-skills@v1.5.2
```
