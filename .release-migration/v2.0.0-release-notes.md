**Agent Skills 2.0 — fresh-start release across the umbrella + all 4 stacks.** Marketplace 2.0.0 + meta/marketing/product/research stacks all 2.0.0. Released as a pre-release on the `refactor/v2.0` branch.

The `main` branch on each repo holds the v1 line (head: [`v1.5.2`](https://github.com/hungv47/agent-skills/releases/tag/v1.5.2)). Existing installs remain on v1.x unless explicitly switched to the v2 trunk.

## What's in 2.0

35 skills across 4 stacks + 7 process-layer skills in meta:

- **research-skills (8):** orchestrate-research, icp-research, market-research, diagnose, prioritize, funnel-planner, short-form-research, short-form-eval
- **marketing-skills (14):** orchestrate-marketing, brand-system, copywriting, ad-copy, cold-outreach, social-copy, short-form-brief, lp-brief, lp-eval, campaign-plan, design-brief, seo, humanize, vn-tone
- **product-skills (6):** orchestrate-product, user-flow, system-architecture, code-cleanup, machine-cleanup, docs-writing
- **meta-skills (7):** orchestrate-meta, discover, agents-panel, eval-loop, task-breakdown, fresh-eyes, cleanup-artifacts

### Foundational shared refs (meta-skills/references/)

The contracts every skill follows: `pre-dispatch-protocol`, `mode-resolver`, `anti-sycophancy`, `artifact-contract-template`, `manifest-spec`, `thin-critic-rubric`, `shared-critic-rubrics`, `playbook-ref-template`, `before-starting-check`, `product-marketing-context-schema`, `eval-loop-spec`, `quality-dashboard-spec`, `quality-feedback-protocol`.

### Knowledge substrate

Cross-session knowledge accumulates at `skills-resources/experience/{domain}.md` (read by every skill on cold-start; written on cold-start answers).

## Install 2.0 (opt-in)

```bash
# Full stack (per-stack):
npx skills add hungv47/research-skills@refactor/v2.0
npx skills add hungv47/marketing-skills@refactor/v2.0
npx skills add hungv47/product-skills@refactor/v2.0
npx skills add hungv47/meta-skills@refactor/v2.0

# Single skill:
npx skills add hungv47/marketing-skills@refactor/v2.0 --skill copywriting
```

## Why pre-release

Marketplace.json reset 5.2.0 → 2.0.0 is a literal version regression. Standard semver tooling treats lower versions as downgrades, so existing v1 installs will not auto-upgrade. The pre-release flag signals "new product line; opt-in." Once 2.0 stabilizes and users are comfortable migrating, the pre-release flag can be lifted.
